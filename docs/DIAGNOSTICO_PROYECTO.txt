- Dominio:         Gestión de horas médicas para consultorios de atención primaria
                   en Chile. Proyecto académico (curso ICI-513, UV).

Apps Django: principal, registro, consultorio (+ admin/auth/sessions de Django)

from django.contrib.auth.backends import ModelBackend
from django.contrib.auth.models import User

def _normalize_rut(value: str) -> str:
    return value.replace(".", "").replace("-", "").strip()

class RutOrEmailBackend(ModelBackend):
    """Autentica por RUT (con o sin puntos/guión) o por correo electrónico."""
    def authenticate(self, request, username=None, password=None, **kwargs):
        if not username or not password:
            return None
        user = None
        # 1. Buscar por RUT normalizado (== User.username)
        normalized = _normalize_rut(username)
        try:
            user = User.objects.get(username=normalized)
        except User.DoesNotExist:
            pass
        # 2. Fallback por email
        if user is None:
            try:
                user = User.objects.get(email__iexact=username.strip())
            except User.DoesNotExist:
                pass
        if user is None:
            return None
        if user.check_password(password) and self.user_can_authenticate(user):
            return user
        return None

FILE: registro/forms.py  (RegisterForm + validación RUT)
--------------------------------------------------------------------------------
Funciones clave:
- validate_chilean_dni(rut): valida formato ^\d{7,8}[0-9Kk]$ y dígito verificador
  (módulo 11). Devuelve bool.
- remove_points_and_hyphens(rut): normaliza el RUT.

class RegisterForm(UserCreationForm):
    TIPO_CHOICES = [('paciente','Paciente'), ('profesional','Profesional')]
    class Meta:
        model = User
        fields = ["username","email","first_name","last_name",
                  "address","phone","birthdate"]   # <-- ver HALLAZGO abajo
    # Campos declarados explícitamente (override): username(=RUT), email, first_name,
    #   last_name, address, phone, birthdate, tipo, especialidad.
    # usable_password = None
    # __init__ personaliza labels (en español), help_texts, placeholders,
    #   error_messages y layout crispy (FormHelper, form_tag=False).
    # clean_username(): valida RUT chileno y lo normaliza.

*** HALLAZGO ***
Meta.fields incluye 'address', 'phone', 'birthdate' que NO son campos del modelo
auth.User. Funciona porque están declarados como form fields explícitos (Django
los toma de la clase, no del modelo), pero esos datos NO se guardan en User al
hacer form.save() — auth.User no tiene esas columnas. Sólo se usan address/phone/
birthdate a nivel de formulario; no persisten en BD salvo que la vista los maneje
(registro/views.py NO los copia a Usuario salvo nombre/apellido/correo).

MIDDLEWARE: stack estándar de Django (security, sessions, common, csrf, auth,
messages, clickjacking). Sin middleware custom.

DECORADOR DE ACCESO: las vistas de consultorio usan @login_required(login_url='/login/').
El control de rol (paciente vs profesional) se hace por consulta:
  Profesional.objects.filter(usuario__rut=request.user.username).exists()

--------------------------------------------------------------------------------
seleccionar_region(request)  [name='consultorio']:
  - GET: lista regiones (agrupadas por c_reg) -> consultorio.html (flujo reserva)
  - POST: crea Reserva. Recibe consultorio, profesional_id, motivo, slot
    ("YYYY-MM-DD HH:MM"). Verifica que el slot no esté tomado (excluye canceladas).
    Guarda 'reserva_confirmada' en sesión. Redirige a principal:principal.
historial_paciente(request) [JSON]: datos de contacto + citas previas de un
    paciente. SÓLO profesionales (403 si no). No incluye info clínica sensible.
obtener_doctores(request) [JSON]: profesionales de un consultorio.
obtener_fechas(request) [JSON]: fechas con Disponibilidad (>= hoy) de un profesional.
obtener_slots(request) [JSON]: genera slots de 30 min entre hora_inicio/hora_fin
    de las Disponibilidades, descontando los ya reservados (no cancelados).
obtener_comunas(request, c_reg) [JSON]: comunas de una región.
obtener_consultorios(request, c_com) [JSON]: consultorios de una comuna.
home(request): render simple de consultorio.html (no enrutada actualmente).
mis_horas(request): historial paginado (15/pág) de citas pasadas/cerradas.
reservar_hora(request): render de "reservar_hora.html"  [TEMPLATE INEXISTENTE — ver hallazgo]
cancelar_hora(request): flujo en 2 pasos con código de 6 dígitos guardado en
